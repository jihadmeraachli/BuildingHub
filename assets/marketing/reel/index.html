Turning this into something you can upload

This is a working motion reference, not a video file. Meta and TikTok need an MP4, so the quickest honest route is to screen record this stage full width, which gives you a usable teaser today for the cost of one take.

For a paid campaign it is worth handing this to a motion designer as the reference instead. The timing, the strike mechanic and the copy are the hard part and they are decided here; rebuilding it properly in After Effects is then a short job with sound design on top.

Runs about 11 seconds, which suits Stories, Reels and WhatsApp status. The Slower control stretches each beat if the Arabic reads too fast, which it will for some viewers.

About the backgrounds. The drawn motifs are placeholders, not photography: scattered paper, a year of bars, chairs around a table with one empty. They exist so the composition can be judged before anyone has shot or licensed anything. Use the Photo for beat row to set each one individually, so you control which image lands on which line. A filled slot shows a tick. Nothing leaves your machine.

Whatever you drop in gets the same treatment: desaturated, tinted into brand teal, and darkened top and bottom so the words always have something to sit on. That is what stops a photo campaign looking like three unrelated stock images. Shoot in Lebanon if you can, in real buildings. A Beirut stairwell earns trust that a generic office lobby never will, and it costs an afternoon.
